# JavaScript Arrays and Functions - Task 15

## Objective
Create JavaScript functions that accept an array as an argument and perform analytical operations: finding the maximum element, calculating the sum, and counting odd numbers.

## Implemented Functions & Paradigms
- `findMax(arr)`: Standard function declaration finding the maximum number.
- `calculateSum(arr)`: Anonymous function expression calculating total element sum.
- `countOddNumbers(arr)`: Arrow function counting odd numbers.

## Sample Execution
- Input Array: `[4, 8, 2, 11, 6, 7, 10]`
- Output:
  - Maximum number: `11`
  - Sum of all elements: `48`
  - Count of odd numbers: `2`
